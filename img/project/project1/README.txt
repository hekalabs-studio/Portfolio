FOTO PROJECT 1 (HekaaPedia)
===========================
Letakkan foto project kamu di folder ini dengan nama:
  1.webp, 2.webp, 3.webp   (bisa ditambah 4.webp, 5.webp, ...)

Lalu buka index.html -> bagian PORTFOLIO -> PROJECT 1,
ganti src tiap <img> menjadi:
  img/project/project1/1.webp  (dst.)

Tips: konversi foto ke .webp biar ringan (mis. squoosh.com).
Rasio foto ideal 16:10 (landscape).
